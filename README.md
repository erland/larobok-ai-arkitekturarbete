# IT-arkitektens roll i AI-eran

Projektpaket för en svensk strategisk lärobok om hur AI förändrar IT-arkitektens arbete och IT-arkitektur i offentlig sektor.

## Innehåll

- `docs/bokspecifikation.md` – projektets grundspecifikation
- `docs/kapitelplan.md` – uppdaterad kapitelplan med strategiska vägval i stället för övningar
- `docs/pedagogisk-canon.md` – canon för ton, nivå, begrepp och kontinuitet
- `docs/terminologi.md` – centrala begrepp
- `docs/projektstatus.md` – arbetsstatus
- `docs/export-metadata.yaml` – metadata för framtida export
- `chapters/` – förberedda kapitelutkast

## Arbetsflöde

Alla 14 kapitel finns nu som utkast. Rekommenderat nästa steg är helhetsgranskning av progression, begrepp, överlapp, källverifiering och exportförberedelser.
